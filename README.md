## 📌 简介

这是我的个人学术主页，用于展示我的研究方向、学术成果和联系方式。网站基于 GitHub Pages 构建，采用纯静态 HTML/CSS 实现。

## 🎨 功能特点

- ✅ 响应式设计，适配各种设备
- ✅ 现代简洁的学术风格
- ✅ 导航栏平滑滚动
- ✅ 移动端友好的汉堡菜单
- ✅ 清晰的时间线展示教育背景
- ✅ 论文列表展示学术成果

```

```

## ✏️ 自定义指南

### 1. 个人信息
编辑 `index.html` 文件，修改以下内容：
- 姓名和职称
- 学校和学院信息
- 联系邮箱和社交媒体链接

### 2. 添加照片
将您的照片命名为 `photo.jpg`（或其他格式），放在项目根目录，然后在 `index.html` 中取消注释照片标签：
```html
<img src="photo.jpg" alt="冯宇翔">
```

### 3. 研究方向
在"研究方向"部分，修改 `research-card` 的内容，包括：
- 图标（使用 [Font Awesome](https://fontawesome.com/icons) 图标）
- 标题和描述

### 4. 论文列表
在"论文发表"部分，按照现有格式添加您的论文：
- 发表年份
- 论文标题
- 作者列表（加粗自己的名字）
- 期刊/会议名称
- 相关链接（PDF、代码、DOI）

### 5. 教育背景
在"教育背景"部分的时间线中，添加您的教育经历。
